# SAR 表面散射与成像质量检查

- 状态：current（2026-10-18 复核）

2026-10-01 第二步：改善首版网格伪影，并量化理想点响应。采集协议与 DCS Export 不变，外部默认引擎升级为 `surface-v2`；不需要重新部署 Lua。

## 改动及假设

首版把 8 m 高程网格顶点直接当成散射点，造成固定格点亮纹。新版每个世界 x/z 的 1×1 m 单元产生一个确定的随机偏移散射点；种子、位置和相位固定，整个孔径重复使用这些点，不逐脉冲重新随机。高程与局部法线仍从原 8 m 高程数据双线性插值得到。点幅度平方按投影地面单元面积缩放，系数仍是假设的 `0.05 + max(入射余弦, 0)`，不代表真实材质或定标后散射系数。

散射位置/相位锚定世界单元，可在重叠切片中保持一致；若两份稀疏高程对同一位置插值不一致，三维位置与相位距离仍会变化。因此不能宣称跨采集 burst 已保持真实相干。不同采样密度可以有不同散斑，但面积缩放避免简单增加点数就增加预期总功率。

默认输出 129×129、1 m 像素。新散射点与像素只细化了假设模型/成像网格，不增加真实地形细节，仍不支持车辆/建筑识别。各图独立峰值归一化，不比较绝对亮度。图像仍有散斑，这是模型中多个固定复数散射贡献的干涉，不应按规则网格伪影同样“消除”。相参散射和散斑定义见 [ASF SAR 用户指南](https://asf.alaska.edu/wp-content/uploads/2019/02/sci-sar-userguide.pdf)。

默认在慢时间孔径和距离频谱两方向使用 Hann 加窗。矩形窗保留为可选对照。Hann 距离压缩包络采用 `sinc(u) + [sinc(u−1)+sinc(u+1)]/2`（峰值归一化），不是对最终灰度图做平滑。孔径权重按真实采样时间与梯形积分权重计算。降低旁瓣与主瓣展宽的取舍见 [Sandia 窗函数研究](https://www.sandia.gov/research/publications/details/sar-window-functions-a-review-and-analysis-of-the-notched-spectrum-problem-2002-09-01/)。这里的波长/带宽/散射与权重是项目设定，不对应某型机载雷达。

为控制计算成本，包络使用查找表，幅度插值误差对解析包络检查小于 1e−7；传播相位始终按实际三维距离计算，不查表或量化。距离采样间距为理想矩形分辨尺度的 1/8、核截断至 ±16 个尺度。复数距离插值改为三次插值，修复线性插值在单点实验中约 0.07 m 的峰位偏差。首版保留为 `reconstructLegacy`，用于冻结旧模型对照；其旧图像和简化不改写。

## 测量方法与结果

`scripts/sar_quality_probe.cjs` 的点实验使用独立理想平地场景：20 km 斜视地距、4 km 平台高度、250 m/s、2 s、121 个位置；几何与新引擎一致。相位合成和聚焦仍共享精确轨迹，因此额外检查解析宽度、频谱数值积分、抹相位、毫米级时变距离误差，而不把自洽结果当作外部雷达验证。

FWHM 为主峰半功率宽度；PSLR 为主瓣之外最大功率/峰值（dB）；ISLR 为主瓣之外积分功率/主瓣积分功率（dB）。主瓣界限取最近两侧第一个局部最小值，使用 1D 横向/地距截面 ±12 m、0.01 m 步长。ISLR 不包含截面之外的尾部，不是 2D 全图积分旁瓣指标。

| 检查 | 矩形窗 | Hann 窗 |
|---|---:|---:|
| 横向 FWHM | 0.753 m | 1.225 m |
| 地距 FWHM | 1.796 m | 2.919 m |
| 横向 PSLR | −13.27 dB | −31.45 dB |
| 地距 PSLR | −13.62 dB | −31.84 dB |
| 横向 1D ISLR | −10.05 dB | −32.85 dB |
| 地距 1D ISLR | −11.48 dB | −33.33 dB |
| 主峰定位 | 0 m | 0 m |

独立矩形解析 FWHM 预期为横向 0.740 m、地距 1.805 m，误差均在 4% 内。Hann 主瓣宽约增加 63%，不能把旁瓣改善描述为分辨率提高。

人工格点诊断：在共同 65×65、2 m 网格上，比较内部 8 m 网格顶点的平均功率与其他点平均功率。旧/新矩形对照使用同样线性距离插值，以减少处理差异。此指标只诊断网格功率集中，不是通用质量评分或地物识别分数。平地旧模型约 88.96；2026-10-01 保存的 90 帧 DCS 输入对照为旧网格 27.01、新表面矩形 0.928、新表面 Hann 0.898。接近 1 表明未再将功率系统集中到高程顶点，不表示真实散射正确。

相同实飞输入新版默认用 16,384 个假设散射点、129² 输出，单次合成/聚焦测得约 3.53 s（旧版 289 点、65² 输出约 0.20 s）。工作线程保证计算不堵塞 HTTP；这不是整个波束、大场景或实时雷达更新率的承诺。采集本身仍为 2 s，计算时间另计。本轮没有新增实飞录制，只重算已有两份真实数据中的后一份。

## 使用与复现

实时与回放页面均有“聚焦窗”和“用当前数据重算”；切换窗后重算不查询 DCS、不修改原始记录、不产生新采集文件。暂停任务/Export 已断开时也可以重算已有输入。需要刷新更新后的页面；外部程序改动需要重启接收端，Lua 无需重装。

```powershell
# 与实时 3593 同时开回放；用空闲 TCP 端口，仅监听本机。
node tools/sar_live.cjs --replay 'recordings/sar/<实际录制>.json' --http-port 3595 --tcp-port 0
# 对同一输入生成可独立打开的三图 + 指标表对照 HTML；无外部资源。
node scripts/sar_quality_probe.cjs --record 'recordings/sar/<实际录制>.json' --html 'recordings/sar-preview/surface-comparison.html'
# 不加 --record 时使用合成平地，输出明确标记 synthetic-demo。
node scripts/sar_quality_probe.cjs
```

原始输入没有冻结处理后的图像；新引擎重算会改变纹理。新采集记录选择的 window。为复现旧版本可调用 `reconstruct(scene, {scatterModel:'legacy-grid'})`，新模型可选 seed、1/2/4 m 散射单元、65/129 输出与线性/三次插值（诊断 API，不作为地物真值）。同一模型参数和输入的功率矩阵保持确定性。

后续仍需要真实材质/多散射中心、地形遮挡、天线方向图、噪声、PRF/模糊、独立算法或公开 SAR 数据对照。本轮没有把网格改善替代这些工作，也没有接入 AESA 调度器/座舱。

## 精细模拟波形检查（2026-10-01）

增加标准/精细档：75/150 MHz 模拟带宽，129²/257² 输出，1/0.5 m 间隔；地形和散射样本仍各为 8 m 与 1 m。输入是高程和平台位置，因此这里可以按新带宽重新合成回波；对于真实雷达接收数据，处理软件不能凭空增加已发射/接收的带宽。范围响应与合成孔径的分工参考 [Sandia SAR 原理](https://www.sandia.gov/radar/pathfinder-radar-isr-and-synthetic-aperture-radar-sar-systems/what-is-sar/)。散斑、地表粗糙度和双次反射等见 [ASF SAR 基础](https://hyp3-docs.asf.alaska.edu/hyp3-docs/guides/introduction_to_sar/)。

相同理想平地/孔径/散射单点、Hann，标准与精细地距 FWHM 分别为 2.918745/1.465658 m；横向 1.224652/1.224627 m。地距比约 0.502，旁瓣仍低于 −30 dB。横向由既有孔径限制，本次没有延长积累时间。0.5 m 输出减轻较窄模拟响应的栅格表示限制，但不能提供缺失的地物几何。

使用同一 90 帧 DCS 录制生成三图：标准40 dB、标准30 dB、精细30 dB。前两图共用同一功率矩阵，仅灰度变化；后两图用相同显示范围，便于查看聚焦/纹理差别。精细纹理更细，仍以假设散斑为主，没有可辨认建筑输入。单次同进程标准/精细耗时 3.94/3.38 s，不是公平速度基准（包括 JIT、系统负载等影响）；独立回放 worker 精细档约 4.23 s，不据此宣称加速。

```powershell
node scripts/sar_precision_probe.cjs 'recordings/sar/<实际文件名>.json' 'recordings/sar-preview/precision-comparison.html'
node tools/sar_live.cjs --replay 'recordings/sar/<实际文件名>.json' --quality fine --http-port 3595 --tcp-port 0
```

对照报告、截图和输入留在忽略目录。默认显示 30 dB，只做局部灰度映射；20/40 dB 可选，不进行锐化、纹理生成或把平滑称为更高分辨率。页面可选的多视降斑（默认 2×2）在显示前对线性功率做块均值，是明确的视数–分辨率取舍，同样不提高分辨率。更密地形查询与建筑接入尚未实现。

## 阴影与叠掩（2026-10-10）

判读层面阴影是"像不像真 SAR"的第一观感因素（[实机使用调研](research/sar-real-world-usage.md) §5 第 1 条：判读一半信息来自阴影），本轮把 SAR 小块路径的遮挡与叠掩显式建模并设为默认行为。改动只在外部计算侧（`tools/sar_scattering.cjs`、`tools/sar_surface.cjs`），采集协议、页面与 Lua 不变。

### 改造前的现状

`sar_scattering.cjs` 已经有逐点遮挡：DEM 射线行进（`terrainBlocked`）与有向包围盒（`boxBlocked`），但它们只在 `sceneModel:'classified'` 的逐脉冲 `amplitude()` 里生效，且每个（散射点 × 脉冲）都重算一次；默认 `uniform` 模型完全不遮挡。`sar-in-mission.md` 里"对倾斜、起伏地形的阴影/叠掩尚未建模"的表述在 classified 模型出现后已经过时，本轮一并改正。

### 现在的模型

- **阴影**：每个散射点先做一次遮挡判定，被挡的点不进回波（幅度等价于 0）。判定用 `terrainBlocked`（DEM 半格步长射线行进，只看切片内的已知地形）与 `boxBlocked`（有向盒，测试所有不属于该点的盒，因此建筑会给地面投下阴影）。两种情形挡不住：切片外地形未知（元数据保留 `outside patch unknown`），以及叠掩——"倒向雷达"是几何正确的位置，不是遮挡。
- **判定次数**：默认 `shadowLook:'center'`，按孔径中点的一次视线判定，结果记在点上供整段孔径复用。取舍依据：2 s 孔径内平台横向移动约 350–500 m、视线方向变化约 1.4°，实测一条横跨切片的脊线在整段孔径内判定完全一致（1024 点、0 点翻转），20 m 方盒只有 2 点翻转（1624 点中的 0.12%）；而逐脉冲判定要付"散射点 × 脉冲"次射线行进的代价（本机 205 脉冲的切片约 +3.5 s）。需要严格逐脉冲时可显式设 `shadowLook:'pulse'`。
- **叠掩**：不需要新代码。合成对每个散射点使用精确三维斜距，影像网格定义在地表上，因此高于 DEM 的立面/屋顶回波落在"斜距相同、地距更近"的格上，即叠掩；位移量约为 H·h/g（H 为雷达高出地面的高度、h 为地物高度、g 为地距）。地形本身不受影响：影像网格跟随 DEM，等价于地形校正产品，地形起伏以几何正确的位置出现而不折叠——这是网格定义的结果，本轮不改。

### 测量与断言（`node --test tests/test_sar_surface.cjs tests/test_sar_scattering.cjs`）

| 场景 | 检查 | 结果 |
|---|---|---|
| 128 m 切片、12 m 高横跨切片的脊线 | 脊后地面功率 | 全部为 0（≤ 峰值 −69 dB）；无阴影对照同区为峰值 0.001–2.9，区域均值高 10³ 倍以上 |
| 同上 | 被挡散射点 / 脊前地面 | 7099/16395（43%）被挡；脊前地面均值变化 < 10% |
| 20 m 方盒（uniform） | 盒底与盒后地面 | 全部 ≤ 峰值 −40 dB；盒前地面保持不变 |
| 20 m 方盒（classified） | 阴影方向 | 阴影落在离雷达更远一侧，近侧为盒体自身亮回波 |
| 2 m 厚、40 m 宽、25/100 m 高墙 | 叠掩位移 | 回波质心地距 −3.2 / −16.7 m（都在雷达一侧）；100 m 墙峰值 −20 m，与 H·h/g = −19.8 m 相符；越过自身足迹落到雷达一侧的能量占比 0.3% → 87% |
| 单点几何 | 斜距排序 | 24 m 高立面顶部比其下地面近 H·h/g，误差 < 5% |
| 平地 | 开关对照 | `shadow:false` 与默认的功率矩阵逐位相同（没有可挡的东西） |
| 横跨切片的脊线 | 两种判定方式 | `shadowLook:'center'` 与 `'pulse'` 的功率矩阵逐位相同 |

### 性能

遮挡判定是唯一的净增成本：16384 点、129² 输出做一次单视线判定 + 有向盒测试约 15–20 ms（一次 4.7 s 合成的 0.3–0.4%）。被挡的点在合成前跳过，所以净合成时间通常下降（本机串行、同一输入）：

| 场景（129² 输出） | `shadow:false` | 默认（`shadow:true`） |
|---|---:|---:|
| 512 m / 4 m 散射、平地、uniform、121 脉冲 | 4784 ms | 4248 ms（−11.2%） |
| 128 m / 1 m、脊线 + 方盒、classified、205 脉冲 | 7930 ms | 4560 ms（−42.5%） |
| 512 m / 4 m、脊线、classified、825 脉冲 | 31329 ms | 28859 ms（−7.9%） |

并行池路径不变：散射点（含遮挡标记）由主线程一次生成后传给 worker，串并行仍逐位一致（`tests/test_sar_pool.cjs` 逐字段比较元数据），本机 128 m 标准档 classified 串行 4560 ms → 6 worker 1153 ms。

### 元数据与开关

`metadata` 新增 `shadow`、`shadow_look`、`shadowed_scatterers`、`shadowed_terrain`、`shadowed_objects`、`shadow_objects`（参与投影的盒数，`uniform` 也计入）、`layover`（文字说明）与改写的 `visibility`。引擎设置里 `shadow:false` 作对照开关、`shadowLook:'pulse'` 作严格判定；页面与服务当前使用默认值（开），没有 UI 开关——那需要改 `sar_live.cjs` 与页面，属于另一批改动。

### 边界

- 切片外地形的遮挡未知（射线只查切片内 DEM）：雷达与切片之间的地形仍可能挡住一些点，本轮不查，`visibility` 里的 `outside patch unknown` 就是这个意思。
- 建筑仍是包围盒而非网格，立面回波没有二次散射/角反射增强，屋顶与墙面亮度仍是假设系数 × 余弦入射。
- 阴影区不是绝对零：强回波的距离/方位旁瓣会漏一点（实测脊后 ≤ −69 dB、盒后 ≤ −40 dB），与真实系统有噪声底的情形同类；图像不新增噪声底。
- 逐脉冲判定只改变阴影边缘的判定，边缘之外两种方式结论一致。
