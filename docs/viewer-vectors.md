# 速度方向与预测线

- 状态：current（2026-10-18 复核）

B-scope 横轴是方位角、纵轴是距离。近距目标相同的世界位移可以对应很大的方位角变化，因此仅将外推距离限制在量程的 30% 以内，仍可能画出很长的屏幕线段。

从航迹符号向前延伸的实线表示估计的世界速度方向，虚线表示沿此速度继续运动的预测。实线最多预测 15 秒，含虚线最多预测 60 秒；世界位移仍受当前量程（俯视图为量程半径）的 30% 限制。本机位置与朝向固定在当前时刻，不预测本机未来运动。

两种视图共用额外的屏幕路径长度限制：

- 实线最多 48 CSS 像素，实线与虚线合计最多 96 CSS 像素。
- 小窗口合计最多绘图区短边的 20%，实线最多其一半。
- 达到限制时沿世界运动轨迹缩短预测时间，按最多 1 秒的间隔投影绘制。线长不能直接作为速度读数。

以上数值是原型显示设定，不是某型实装 AESA 雷达的符号规范。原有 400 m/s 显示过滤阈值继续保留；它是显示保护设定，不是飞机物理速度上限，也不能据此判定航迹速度可信。

贯穿 B-scope 上下的竖线表示波束扫描位置；淡色连续曲线是历史尾迹。它们不属于本次速度/预测线限长范围。距离标签中的 `c` 表示闭合速度，而不是目标自身速度。

验证命令：在 `aesa/` 下运行 `node --test tests/test_viewer_vectors.cjs`。测试直接执行页面脚本并记录 Canvas 绘图，覆盖两种视图、近距角度放大、小窗口、时间与世界距离上限、近距穿越和无效速度字段。

此修复只调整显示，未调整 tracker 的关联或速度估计。截图不能单独验证各航迹的真实速度，后续实飞需结合录制和真值对照。
