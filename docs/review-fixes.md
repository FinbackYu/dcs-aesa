# AESA 审查修复

- 状态：historical（2026-10-18 归档）

日期：2026-09-30。本轮修复此前项目审查和物理模型审查中的实现缺陷，并明确剩余模型假设。

## 项目实现

| 问题 | 修复 | 回归依据 |
|---|---|---|
| 残缺 END 导致 Export.lua 后续内容被截断 | 写入前验证标记完整性、顺序、唯一性和独占行；异常时保留所有原文件 | malformed_markers |
| 未知同名脚本被覆盖 | SHA256 清单验证归属；未知或本地修改过的文件拒绝升级/卸载；已知旧版可迁移 | unknown_script / changed_owned_script |
| 外部编码/换行被重写、备份不完整 | 按字节修改；自动备份不同原始版本；失败回滚；保留其他工具后来追加的内容 | export_bytes / external_export_edits / install_io_failure |
| 卸载被外来文件阻止或误删日志 | 只删除已验证脚本和自身清单；保留备份、日志、外来文件 | uninstall_preserves_logs |
| 调度回访随 dt 改变、迟到统计虚假、检测提前输出 | 按事件时刻调度，保留实际截止期；完成后输出，pending 单独入账 | dt_partition / detections_after_dwell / T7、T9 |
| 现有航迹 STT 模式或近远距频率不更新 | 每次刷新同步模式/频率，按实际回访轮换波形 | stt_upgrade_downgrade |
| E 行字段错位 | 同时修正带坐标/不带坐标两种偏移 | engine_fields_both_formats |
| 实时长间隔丢失时间 | 完整分段步进，重复/倒序帧不破坏时间轴 | live_gap |
| 无 Position 的对象使整帧失效 | 校验有限三维坐标后再计算距离 | export_skips_object |
| 显示世界位置停留在最后观测时刻 | 以航迹速度外推到当前显示时刻，与机体视图一致 | live_offline |
| 回放汇总将已删除的航迹 ID 空洞当作有效航迹 | 将航迹表按映射遍历并排序，不用 Lua 序列长度取航迹 | replay_summary_handles_deleted_track_ids |

## 物理模型

| 问题 | 修复或明确的边界 |
|---|---|
| 主瓣 notch 未折叠多普勒混叠，与绝对零速度滤波混淆 | 折叠相对杂波中心的速度差；零多普勒滤波单独配置 |
| 遮蔽只在 Ru 单侧强制归零 | 计算矩形回波与两个相邻发射脉冲的重叠，双侧部分遮蔽降低 SNR |
| 无视距、无地形接口 | 默认有效地球球面视距；支持 target.visible/truth:is_visible 和 Export 可选 L 行。无地形信息明确记录 unknown |
| 扫描锥按 az/el 矩形裁剪 | 按 acos(cos el·cos az) 检查真扫描角，跳过锥外任务 |
| 所有门内目标都取峰值增益，两轴展宽相同 | 阵面方向余弦中的高斯主瓣，乘收发双程损失；主瓣门为 HPBW 椭圆近似 |
| 扫描指数改变后驻留补偿不匹配 | 使用 cos^(-2k) 驻留补偿 |
| 搜索只用中 PRF，600m 目标无法起始；20k/200k 共有盲区 | 搜索每个位置使用四种波形，跟踪/STT 按实际回访轮换；添加 18k/164k，仍不保证无共同盲区 |
| LPRF 使用同样 2kW 导致隐含 1MW 峰值 | 峰值功率上限 20kW【假设】；LPRF 实际平均功率为 40W。notch 半宽降为 5m/s，默认搜索不使用 LPRF |
| 固定 250km 截断大 RCS 目标 | 默认去掉截断；可配置计算上限并记录 range-limit |
| 速度方向代替机头，无 pitch/roll | 同一三维机体正交基用于探测、指向和反解；O 行传递姿态，旧录制保留平飞回退 |
| 任意驻留都理想相参；相邻 CPI 起伏完全独立 | 相参效率/有效相参时间可配置；默认 0.25s 相关窗保持目标功率，每 CPI 独立接收噪声。相关窗是显式假设，单 CPI 闭式由 Monte Carlo 验证 |

公式和公开一手依据见 [理论笔记](theory-notes.md)；协议、开发验证部署、修复和卸载见 [数据层设计](design-phase2.md)。

## 验证

- 原有测试 22/22；新增回归 38/38，共 60 项。覆盖纯核心、导出桩、姿态/遮蔽字段、实时/回放、临时目录安装/修复/卸载、损坏清单、旧版卸载和写入故障回滚。
- 使用 DCS 自带 Lua 5.1 检查 11 个 Lua 文件语法；开发验证部署前也先检查 Export。
- 当前仍处于早期开发阶段，不生成发布包；修复保留在源码、测试与文档中，部署清单仅用于保护用户文件。
- 真实历史录制 flight3-final 最大会话：1608 帧、168.3s，3366 次步进、15774 次完成驻留，最终 6 条确认航迹；回放汇总成功。旧录制缺 O/L，不能据此验证新姿态和地形接口。
- 本轮未部署新版至实际 Saved Games 或 DCS 安装目录。Export 沙箱地形接口可用性、姿态符号及性能需实飞验证。

## 对结果的影响

四个 CPI 完成一个搜索位置会增加搜索帧时间。周期 notch、遮蔽、波束偏离和相关起伏都可能减少检测，任务回访频率不等于成功检测频率。

这仍是每驻留一次判定的原理级模型：没有完整波形处理、距离/速度解模糊、空单元虚警、CFAR、真实杂波图、气象或经实测标定的姿态 RCS。默认相参效率为理想上界。以上限制已写入理论笔记，不能解释为已达到实装雷达精度。
